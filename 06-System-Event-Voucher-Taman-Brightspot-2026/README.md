# System Event Voucher – Taman Brightspot 2026

## Project Overview

This project contains Software Quality Assurance (SQA) testing documentation for the System Event Voucher – Taman Brightspot 2026.

The testing covered multiple system modules and validated the end-to-end voucher workflow, including user access, registration, transaction processing, voucher management, voucher validation, voucher transfer, voucher claims, and reporting.

## My Role

Software Quality Assurance (SQA) – Manual Testing

## Testing Information

- Testing Type: System Integration Testing (SIT)
- Testing Method: Manual Testing
- Testing Focus: End-to-End Voucher Workflow and Transaction Validation

## Testing Scope

The testing covered the following modules and functionalities:

- Login
- Dashboard
- Register Foto
- Register OCR
- Data Transaksi
- Transfer Voucher
- Klaim Voucher
- Cek RRN
- Cek Voucher
- Upload Voucher

## Testing Activities

The testing activities included:

- Executing SIT test cases
- Performing functional testing
- Validating positive and negative scenarios
- Validating transaction data
- Validating voucher-related workflows
- Performing end-to-end workflow testing
- Validating input and business rules
- Identifying and documenting system defects
- Verifying system behavior against expected results
