# SQA Bootcamp Project Briefing & Technical Orientation

## Project Overview

This project documents my experience conducting QA project briefings and technical orientation sessions for SQA Bootcamp participants.

The session was conducted via Zoom to help participants understand the assigned application before starting their final testing projects.

## My Role

Software Quality Assurance (SQA) – Project Briefing and Technical Orientation

## Activities

- Conducted QA project briefings and technical orientation sessions for SQA Bootcamp participants
- Explained the assigned application's modules and key features
- Explained user flows and system functionality
- Introduced the testing scope and project requirements
- Conducted step-by-step walkthroughs of key application features and modules
- Guided participants in understanding the assigned website before performing testing
- Clarified testing objectives and functional areas to be tested

## Skills Demonstrated

- QA Knowledge Sharing
- Technical Communication
- Application Walkthrough
- Testing Scope Explanation
- Project Briefing
- Functional Requirement Explanation
- Stakeholder Communication
