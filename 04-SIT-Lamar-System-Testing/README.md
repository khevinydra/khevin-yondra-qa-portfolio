# SIT Lamar System Testing

## Project Overview

This repository contains Software Quality Assurance (SQA) testing documentation for the SIT Lamar System Testing project.

The testing focused on validating system changes, functional requirements, and identified defects during the System Integration Testing process.

## My Role

Software Quality Assurance (SQA) – Manual Testing

## Testing Information

- Testing Type: System Integration Testing (SIT)
- Testing Method: Manual Testing

## Repository Structure

- Test-Documentation: Test cases and testing documentation.
- Test-Evidence: Selected screenshots as evidence of test execution.
- Bug-Reports: Supporting evidence of identified defects.
