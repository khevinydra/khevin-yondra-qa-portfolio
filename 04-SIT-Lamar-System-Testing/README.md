# SIT Lamar System Testing

## Project Overview

This project contains Software Quality Assurance (SQA) testing documentation for the SIT Lamar System Testing project.

The testing focused on validating system changes and performing retesting after previously reported issues were fixed.

## My Role

Software Quality Assurance (SQA) – Manual Testing

## Testing Information

- Testing Type: System Integration Testing (SIT)
- Testing Method: Manual Testing
- Testing Focus: Bug Fix Retesting and Validation

## Testing Scope

The testing focused on validating implemented fixes and ensuring that affected system functionality worked as expected after the bug fixing process.

## Testing Activities

The testing activities included:

- Retesting resolved issues
- Bug fix validation
- Functional validation
- Regression testing on affected functionality
- System Integration Testing (SIT)
- Test result documentation

## Test Evidence

The screenshots in the `Test-Evidence` folder contain evidence of testing performed after the related issues were fixed.

The evidence demonstrates that the implemented fixes were validated through retesting and that the tested functionality produced the expected results.

## Testing Artifacts

### Test Documentation

Contains the SIT test case documentation used for bug fix validation and retesting.

### Test Evidence

Contains selected screenshots showing the results of retesting after system fixes were implemented.
