# DIKAONE HRD Master Zip Code Enhancement

## Project Overview

This project contains Software Quality Assurance (SQA) testing documentation for an enhancement in the DIKAONE HRD module.

The testing focused on validating the addition of Master menu functionality related to Province, City, Village, District, and Zip Code data.

## My Role

Software Quality Assurance (SQA) – Manual Testing

## Testing Information

- Testing Type: System Integration Testing (SIT)
- Testing Method: Manual Testing
- Testing Focus: Feature Enhancement and New Menu Validation
