# System Event Cashback – Astindo Travel Fair PIK Avenue 2026

## Project Overview

This project contains Software Quality Assurance (SQA) testing documentation for the System Event Cashback – Astindo Travel Fair at Mall PIK Avenue 2026.

The testing was performed to validate system functionality, user input validation, business rules, security-related scenarios, and end-to-end transaction processes.
